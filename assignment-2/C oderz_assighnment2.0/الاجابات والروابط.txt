السؤال الأول: ما الذي تغيّر على جهازك بعد Pull؟ ومتى وصل قسم الروابط إلى main؟
بعد ما نعمل Pull يتم تحديث أي ملف داخل ال ريبو اللي انا فاتحها علىعلى جهازي بالتعديلات الأخيرة اللي موجوده على Github , ويصل قسم الروابط الى ال main بعد عمل الموافقه لل ال pull requset وعمل Merge .


السؤال الثاني: لو عدّل شخصان نفس السطر وظهر Merge Conflict، كيف تحافظ على التعديلات المطلوبة وتفحص الصفحة قبل رفع الحل؟
زي مثلا انا في ال h2 : <h2>روابط مفيدة</h2>  وصاحبي او الشخص اللي معي عمل هيك : <h2>مصادر تعليمية</h2> طبعا لازم يكونو نفس السطر !!
هيك تعارض لانو احنا عدلنا نفس السطر , الحل بنتفق على تعديل نهائي او بندمج تعديليي وتعديله بصير زي هيك مثلا <h2>روابط ومصادر تعليمية</h2> وبعدين بنعمل  git add لتجهيز التعديلات لل commit وبعدين بنعمل  commit وبعدين Push
